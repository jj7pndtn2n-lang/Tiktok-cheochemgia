# Agar Web — bản thử nghiệm

Bản game web lấy cảm hứng từ cơ chế Agar.io, viết bằng HTML/CSS/JavaScript thuần.

## Chạy thử
Mở `index.html` trong trình duyệt hiện đại.

## Đăng lên GitHub Pages
1. Tạo repository công khai, ví dụ `agar-game`.
2. Thêm `index.html` ở thư mục gốc và commit.
3. Vào Settings → Pages.
4. Trong Build and deployment chọn `Deploy from a branch`, branch `main`, folder `/(root)`, nhấn Save.
5. Mở đường dẫn được hiển thị trong mục Pages.

## Tính năng hiện có
- Di chuyển cảm ứng/chuột
- Bản đồ rộng, camera theo người chơi
- Thức ăn và tăng kích thước
- Bot cơ bản có di chuyển và tương tác ăn/nuốt
- Bảng xếp hạng và minimap A1–D4 chỉ đánh dấu người chơi

Đây là prototype phía client; chưa có multiplayer trực tuyến hoặc máy chủ lưu trạng thái.
